# 源码发布快照的验证范围

- 源文件从正式版 4 的运行清单白名单选取，480 个 Python / Web / 明确许可的资源文件保持原始字节。原生核心使用对应正式版与 B2 的源包，不从二进制反推代码。来源表记录了哪些 B2 发布包装代码与桌面正式版不同。
- 不含用户配置、工程、恢复副本、录音、权重、令牌、安装包、编译产物及复制的运行环境。保留了使用所需的第三方许可、原作者归属与明确授权的字体和界面资源。
- 经 Windows Python 3.10 检查：源码 CLI 帮助、合成 MIDI 的结构读取、启动器只读检查和 Python 语法通过；界面 JavaScript 语法检查通过。
- 在这个发布源码树的非产品目录中验证了 x64 CMake 配置：编辑器核心、VST 宿主及 GPLv3 PortAudio/ASIO。谱面 overlay 源的前序参考包，用重新编译的 zlib 生成过 Ninja 构建配置；本仓库保留 overlay，需要开发者准备相同的上游树。
- 此次源码整理不是整套二进制重建。未运行桌面 GUI、未连接或改变实际音频设备、未在新解释器联网安装全依赖，也未使用私有项目或媒体做回归。
